# Abbasia Sunday Crew app icon

The supplied Abbasia Sunday Crew artwork is installed as the app icon.

Files:
- `icon-512.png` — main PWA/app icon
- `icon-192.png` — Android/PWA icon
- `icon-180.png` — iOS home-screen icon
- `favicon-32.png` — browser tab favicon

`index.html`, `manifest.json`, and `sw.js` are already wired to these files.

For GitHub Pages, make sure the repository serves the root `index.html`.
For Firebase Hosting, deploy the package normally with the included `firebase.json`.
